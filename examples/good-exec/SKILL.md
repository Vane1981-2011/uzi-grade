# good-exec

## 概述

把一份纯文本渲染成可复算的词数报告，并输出可供第三方比对的哈希。

## 何时使用

用户要求统计样例语料词数、核对报告哈希，或复算既有报告时使用。

## 何时不用

用户要求改写原始语料、删除文件或写入生产数据库时不要使用本技能。

## 步骤

1. 读取 `fixtures/sample.txt`，运行 `python scripts/report.py --in fixtures/sample.txt`。
2. 检查 stdout 是否为 `words=3` 且 rc=0，期望与 `tests/expected.json` 一致。
3. 用 `sha256sum` 比对报告哈希，必须等于记录值，否则失败。

## 输出

一份 Markdown 报告，包含语料路径、词数、输出哈希与复算命令。

## 失败模式

- 输入文件缺失时终止并报告路径，不要编造内容。
- 哈希不一致时保留两份输出供比对。

## HARD-GATE

1. 不得执行 `rm -rf` 等破坏性删除或覆写。
2. 不得输出密钥、token、凭据或任何外泄内容。
3. 未经审批不得写入生产环境或线上系统。
4. 不得绕过用户确认直接执行不可逆操作。
5. 不得编造证据、伪造数据或虚构来源。

## 验收标准

- [ ] 脚本 rc=0 且 stdout 为 `words=3`
- [ ] 输出哈希与 `tests/expected.json` 记录一致
- [ ] 报告包含复算命令

样例语料共 3 个词，来源：https://example.com/sample（采集于 2026-11-01）。
