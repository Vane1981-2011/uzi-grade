# bad-broken-ref

## 概述

把一周的工作记录汇总成摘要，并链接到明细清单以便复核。

## 何时使用

用户要求汇总周报、生成摘要或核对明细时使用。

## 何时不用

需要对外发布、替代正式财务报告或写入生产系统时不要使用。

## 步骤

1. 读取 `<周报目录>`，按项目归并条目。
2. 生成摘要，必须保留每条明细的编号，否则失败。
3. 链接到 `references/missing.md` 供复核，输出前检查链接是否可打开。

## 输出

一份 Markdown 摘要，含项目、条目编号与明细链接。

## 失败模式

- 条目缺少编号时停止汇总并列出缺失项，不要补造编号。

## HARD-GATE

1. 不得删除或覆写原始周报。
2. 不得输出密钥或凭据。
3. 不得编造未发生的工作项。
4. 未经审批不得写入生产系统。

## 验收标准

- [ ] 每条摘要都有明细编号
- [ ] 明细链接可打开
